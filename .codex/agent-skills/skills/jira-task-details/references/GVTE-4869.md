## Description

Rename the existing "Codex API" into a unified "Metrics API" that consolidates data from all
sources: Web usage, Codex, and Claude. This will provide a single source of truth for usage metrics.

## Acceptance Criteria

- Codebase (endpoints, services, modules)
- Documentation
- Configuration files
- Database references
- Integrate Aitrium web usage data:
- Implement source identification/tagging
- Capture token usage from web interactions
- Ensure data consistency with existing sources
- Add source discrimination to API responses:
- Include source field/identifier (values: "web", "codex", "claude")
- Support filtering by source
- Aggregate metrics across sources
- Implement token capture for web usage:
- Hook into web request/response cycle
- Extract token counts from API responses
- Store with proper source attribution
- Update API documentation (OpenAPI/Swagger)
- Create migration guide for consumers of old Codex API
- Add metrics to monitor API performance and data quality
- API integration tests covering all data sources
- Load testing to ensure performance with multiple sources
